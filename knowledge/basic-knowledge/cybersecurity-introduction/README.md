
# 01 - Cybersecurity Introduction

## 1. Overview

This lesson introduces the fundamental concepts of cybersecurity and information security.

### Learning Objectives

- Learn the CIA Triad: Confidentiality, Integrity, and Availability.
- Distinguish between Threat, Vulnerability, and Risk.

---

## 2. What is Cybersecurity?

**Cybersecurity** is the practice of protecting computers, networks, applications, and data from unauthorized access, attacks, damage, or theft.

### Main Goals
- Protect sensitive information.
- Prevent unauthorized access.
- Detect and respond to security incidents.
- Maintain the availability of systems and services.

---

## 3. The CIA Triad

The CIA Triad is a fundamental model used to understand the goals of information security.

| Principle | Meaning | Example |
|---|---|---|
| Confidentiality | Only authorized people can access information. | Encrypting personal data. |
| Integrity | Information remains accurate and is not changed without authorization. | Using hashes to verify file integrity. |
| Availability | Systems and data are accessible when needed. | Using backups and protection against DDoS attacks. |

### Example

When protecting an online banking system:

- **Confidentiality:** Only the account owner can view their balance.
- **Integrity:** Unauthorized users cannot modify transaction details.
- **Availability:** Customers can access the banking service when needed.

---

## 4. Threat, Vulnerability, and Risk

| Concept | Definition | Example |
|---|---|---|
| Threat | Something that can cause harm to a system. | A hacker attempting to steal data. |
| Vulnerability | A weakness that can be exploited. | A system using outdated software. |
| Risk | The possibility and impact of a threat exploiting a vulnerability. | An attacker exploits outdated software and steals data. |

### Relationship

A threat may exploit a vulnerability, resulting in a security incident and causing risk to an organization.

**Simple example:**

- Threat: An attacker.
- Vulnerability: A weak password.
- Risk: The attacker may access the account and steal information.

---

## 5. Common Cybersecurity Attacks

| Attack | Description |
|---|---|
| Phishing | Tricking users into revealing sensitive information. |
| Malware | Malicious software designed to damage or compromise systems. |
| Ransomware | Malware that encrypts files and demands payment. |
| Brute Force | Trying many passwords until the correct one is found. |
| DDoS | Overwhelming a service with traffic to make it unavailable. |
| SQL Injection | Injecting malicious SQL commands into an application. |

---

## 6. Basic Security Practices

- Use strong and unique passwords.
- Enable Multi-Factor Authentication (MFA).
- Keep operating systems and applications updated.
- Avoid suspicious links and attachments.
- Back up important data regularly.
- Use least privilege: give users only the permissions they need.

## 8. Key Takeaways

- Cybersecurity protects systems, networks, applications, and data.
- The CIA Triad consists of Confidentiality, Integrity, and Availability.
- Threat is a potential cause of harm.
- Vulnerability is a weakness that can be exploited.
- Risk is the possibility and impact of a threat exploiting a vulnerability.
- Good security practices reduce the likelihood and impact of attacks.
